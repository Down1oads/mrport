# Mr. President!

Ported By Down1oads

Play: https://down1oads.github.io/mrport/

Desktop browser controls: WASD to move, Space to jump, hold left mouse to dive, hold right mouse for slow motion. E performs a front flip; Z a backflip; H dances; V poses. Escape opens the in-level menu; Space closes it, R retries, and Escape returns to the room.

The data and engine are gzip-compressed and split into files below GitHub's file limit. The page streams and decompresses them in the browser. The loading screen reports the compressed payload loaded/total MB and the current stage. A modern desktop browser with WebGL2 and Compression Streams support is required.

Published runtime revision: 054aed583b00. Lobby mouse capture, Escape menu and emote interruption fixes are included.
